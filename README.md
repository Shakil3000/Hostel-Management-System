\# Hostel Management System



A console-based Hostel Management System written in C++ for managing boarder records.



\## Features



\- Add and store boarder details

\- View boarder information

\- Simple menu-driven console interface



\## Tech Stack



\- Language: C++

\- Platform: Windows (console application)

\- IDE: Visual Studio Code



\## How to Run



1\. Clone the repository:

&#x20;  git clone https://github.com/Shakil3000/Hostel-Management-System.git

2\. Open Hostel\_Manegment\_System.cpp in any C++ IDE

3\. Compile and run the program (for example: g++ Hostel\_Manegment\_System.cpp -o hostel)
